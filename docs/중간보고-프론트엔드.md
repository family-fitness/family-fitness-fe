# 우리가족 체력키움 — 프론트엔드 중간보고

국민체력100 공개데이터 기반 가족 체력 서비스 · 한국스포츠정책과학원 공공데이터 활용 경진대회
담당: 프론트엔드 (이상진)

---

## 1. 무엇을 만들었나

국민체력100 측정 기록을 **가족 단위로 읽는 웹앱(PWA)** 이다.
앱스토어에 올리지 않고 링크로 들어오며, 홈 화면에 설치하면 앱처럼 열린다.

한 계정으로 **부모와 아이가 같이 쓴다.** 로그인하면 누가 쓰는지 고르고,
그 뒤로는 각자의 홈 하나가 중심이 된다.

```
로그인 → 부모·아이 고르기 → (부모 홈 | 아이 홈)
```

**하단 탭바를 쓰지 않았다.** 부모와 아이가 같은 바를 쓸 수 없고,
다섯 칸짜리 탭바는 어느 앱에나 있는 모양이라 이 서비스가 무엇인지 말해 주지 않는다.
**역할 자체가 내비게이션**이 되도록 다시 설계했다.

| 화면 수 | 32개 라우트                                                      |
| ------- | ---------------------------------------------------------------- |
| 부모    | 홈 · 자라는 기록 · 지난 기록 · 가족 초대 · 측정 · 결과 · 10년 뒤 |
| 아이    | 홈 · 운동 고르기 · 운동하기(영상·세기·주사위) · 본 영상 · 칭찬   |
| 공통    | 코치 제안 · 코치 대화 · 영상 · 주간 기록 · 설정                  |

## 2. 핵심 주장 — 코치 제안은 미션이 아니다

이 서비스가 다른 운동 앱과 갈리는 지점이다.

> 주간 코치가 만든 것은 **제안(proposal)** 이고,
> **보호자가 승인해야** 비로소 **미션(mission)** 이 된다.

AI가 짜 준 계획이 보호자 확인 없이 아이에게 내려가지 않는다.
아동 대상 서비스에서 이 경계가 없으면 안 된다고 보고, 화면 문구까지 여기에 맞췄다.

**브라우저에서 실제로 확인한 결과**

| 단계             | 미션 수 |
| ---------------- | ------- |
| 제안 만들기 전   | 0건     |
| 제안을 만든 직후 | **0건** |
| 보호자가 승인    | 1건     |

- 승인 전 화면에는 "미션" 이라는 단어를 쓰지 않는다 → "제안", "이번 주 제안"
- 승인 버튼은 보호자 프로필에만 렌더링된다. 자녀 계정에는 버튼 자체가 없다
- 거절도 1급 동작이고, 사유를 받아 다음 주 편성에 넘긴다

> 사진: `21-코치-제안전` · `22-코치-제안-승인대기` · `23-승인후-미션생김`

## 3. 데이터를 정직하게 말한다

공공데이터 기반 서비스라 **모르는 것을 아는 척하지 않는 것**을 규칙으로 못박았다.

### 3-1. 서버가 실제로 아는 것만 "확인됨" 이라고 쓴다

웹에서 서버가 진짜로 아는 건 **유튜브 재생 진행률**과 **앱 내 타이머** 둘뿐이다.

| 근거             | 화면 표기                    |
| ---------------- | ---------------------------- |
| `VIDEO_PROGRESS` | 영상 완주로 확인됨           |
| `TIMER`          | 타이머로 확인됨              |
| `SELF_REPORT`    | 직접 입력함 · 부모 확인 필요 |

걸음수 같은 자기 신고에 "자동 인증" 을 붙이지 않는다.
놀이에서도 **누른 횟수는 아이가 센 것**이고 **1분이라는 시간만 앱이 기록**한다고 적는다.

### 3-2. 10년 후 예측은 예언이 아니다

국민체력100은 횡단면 조사라 개인 추적이 불가능하다.

- 쓰는 문구: "지금과 같은 조건의 10년 위 연령대는 여기 있습니다"
- 쓰지 않는 문구: "당신은 10년 뒤 이렇게 됩니다"
- p10~p90 신뢰구간 음영을 반드시 같이 그린다. 중앙값만 그리면 확정된 미래처럼 보인다
- 고지 문구는 접거나 지울 수 없게 항상 띄운다

> 사진: `20-10년뒤`

### 3-3. 규준이 없으면 없는 대로 그린다

만 7~10세는 국민체력100 규준이 비어 있는 항목이 있다.
0% 막대를 그리면 꼴찌처럼 보이므로 **비어 있음을 비어 있게** 그린다.

> 사진: `19-측정-결과` — 레이더의 점선이 또래 평균, 기준 없는 요인은 비워 둠

## 4. 아이를 평가하지 않는다

기획서 페르소나 셋(초4 서준 · 워킹맘 은영 · 아빠 도현)에서 규칙 셋을 뽑았다.

1. **통제하지 않는다** — 스마트폰 잠금 같은 기능은 만들지 않는다
2. **죄책감을 주지 않는다** — "당신이 참여하지 않았습니다" 는 앱을 지우게 하는 말이다
3. **아이 화면은 놀이여야 한다** — 서준에게 백분위 표를 보여주면 그걸로 끝이다

이걸 화면 규칙으로 옮겼다.

| 아이에게 보여주는 것        | 보여주지 않는 것                 |
| --------------------------- | -------------------------------- |
| 신체 점수(또래 백분위) 하나 | 등급(1·2·3·참가)                 |
| 이번 주에 움직인 날         | 약한 항목 — "너는 유연성이 약해" |
| 오늘 할 운동 하나           | 형제·가족 구성원 비교            |
| 부모님의 칭찬 한마디        | 연속 기록이 끊겼다는 말          |

- **연속 기록(streak)을 쓰지 않는다.** 하루 빠지면 0으로 돌아가고, 그건 벌이 된다.
  대신 이번 주에 움직인 날만 칠한다
- 등급을 빨강으로 칠하지 않는다. 같은 색상의 명도 단계로만 구분한다
- 아무것도 없는 주에 "0분 · 미션 0／0 · 응원 0번" 을 늘어놓지 않는다

> 사진: `03-아이홈` · `19-측정-결과`(부모 화면과 대조)

## 5. 가족을 잇는 순환

기획서의 "부모가 같이 해 주는 것" 을 기능 하나로 옮겼다.

```
아이 : 오늘 할 운동 → 영상 또는 놀이 → "다 했어요" → 엄마·아빠한테 알리기
부모 : 홈에 "서준이 기다리고 있어요" → 칭찬 한마디 고르기 → 보내기
아이 : 홈에서 부모님의 칭찬 한마디 확인
```

- **칭찬은 부모만 보낼 수 있다.** 아이가 자기에게 칭찬할 수 없어야 받은 말에 값이 생긴다
- **정해진 문구를 고르기만 해도 보내진다.** 퇴근하고 지친 부모에게 글쓰기를 시키면
  그날로 안 보낸다 — 빈 칸만 있는 화면은 닫힌다
- 부모가 아직 안 보냈으면 아이 화면은 "기다리는 중" 이다. 재촉하지 않는다
- 받은 말을 개수 목표로 만들지 않는다. "10개 모으면" 을 붙이면 못 채운 날이 실패가 된다

> 사진: `10-다했어요` → `11-부모에게-알림` → `12-부모홈-알림도착` →
> `13-칭찬고르기` → `15-아이가-받은-칭찬`

## 6. 아이가 직접 쓰는 장치

영상을 끝까지 보는 것보다 **셀 수 있는 것**에 아이가 반응한다.
운동하기 화면에 세 가지를 나란히 뒀다.

| 방식       | 무엇                                          |
| ---------- | --------------------------------------------- |
| **영상**   | 유튜브 재생. 진행률 90% 를 넘으면 서버가 적립 |
| **세기**   | 1분 동안 화면 아무 데나 누르며 직접 센다      |
| **주사위** | 나온 운동을 나온 수만큼. 세 번 굴리면 끝      |

- 누를 곳이 화면 절반이다. 아이는 작은 버튼을 잘 못 누른다
- 누를 때마다 조각이 튄다(three.js — 1분에 40번 × 8조각 = 320개)
- 주사위는 **바로 앞에 나온 운동을 빼고** 뽑는다. 같은 게 연달아 나오면 고장 난 것으로 보인다

> 사진: `05-운동하기-영상` · `06-세기놀이` · `07-세기놀이-누르는중` · `08-주사위놀이`

## 7. 화면을 그림으로 채웠다

**글만으로 화면을 채우지 않는다.** 특히 빈 화면은 글만 있으면 오류난 화면처럼 보인다.

- 에셋 **221장**을 직접 명세(`ASSET_PROMPTS.md`)해서 생성·반영
- 캐릭터는 **8프레임 연속 그림**으로 실제로 움직인다
- 부품(몸통·머리·표정·옷)을 따로 뽑아 겹친다. 구성원이 늘어도 다시 뽑지 않아도 된다
- 배경은 조각을 흩뿌리지 않고 **가로로 긴 장면 한 장**을 깐다
  (흰 배경에 구름·별을 띄우면 이모지를 뿌려 놓은 것처럼 보인다)

받은 프레임 64장 중 **13장이 쓸 수 없는 상태**였다 — 한 장에 캐릭터가 여러 명 들어간 격자,
캐릭터 주변에 파란 소용돌이가 그려진 것. 에셋 준비 스크립트가 이걸 **자동으로 걸러낸다.**
알파 채널을 가로·세로로 눌러 잉크 덩어리 개수를 세고(격자면 여럿), 묶음 안 최소 너비보다
2.5배 넓으면 장식이 붙은 것으로 본다. 쓸 수 있는 프레임 번호만 코드로 내보내
화면이 망가진 장을 건너뛴다.

### 색

국민체력100 공식 사이트에서 그대로 가져왔다.
공공데이터 기반 서비스라 그 기관의 색을 쓰는 게 맞고, AI가 기본값으로 뱉는 색을
피하는 방법이기도 하다.

| ------------- | --------- |
| 배경          | `#FFFFFF` |
| 포인트        | `#2784E6` |
| 진한 포인트   | `#1B2574` |
| 기록 강조     | `#FFB800` |
| 해냈다는 표시 | `#1F8A5F` |

## 8. 홈 화면에 설치되는 앱

앱스토어에 올리지 않으므로 **매니페스트가 곧 앱 등록**이다.

- 매니페스트 · 아이콘 6종(에셋에서 자동 생성) · 바로가기
- 서비스워커 — 인터넷이 끊겨도 우리 화면이 뜬다
- **API 응답은 저장하지 않는다.** 어제 점수를 오늘 점수인 척 보여주는 건
  아무것도 안 보여주는 것보다 나쁘다. 저장하는 건 화면 뼈대와 그림뿐이다
- 확대를 막지 않는다. 앱처럼 보이려고 `userScalable: false` 를 쓰는 관행이 있는데
  작은 글씨를 키워 보는 사람에게서 그 방법을 빼앗는 일이다

> 사진: `27-인터넷-끊김`

## 9. 어떻게 검증했나

손으로 눌러 보며 찾던 것들을 **돌리기만 하면 되는 검사**로 옮겼다.

| 명령                    | 무엇을 보나                                                                                                           |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------- |
| `npm run verify`        | 서식 · 린트 · 타입 · 에셋 참조 · **도메인 규칙 28개**                                                                 |
| `npm run check:screens` | 30개 화면 — 콘솔 오류 · 가로 스크롤 · 빈 화면 · 제목 개수 · 누름 자리 크기, 그리고 **아이 모드에서 부모 말이 새는지** |
| `npm run check:clicks`  | 24개 화면의 버튼·링크를 하나씩 눌러 보고 터지는지                                                                     |
| `npm run check:down`    | **백엔드를 500 으로 막고** 화면마다 사실대로 말하는지                                                                 |

`check:down` 은 이번에 가장 많은 것을 잡았다. 백엔드를 전부 막고 19개 화면을 열어 보니

| 화면      | 서버가 죽었을 때 하던 말    | 실제                  |
| --------- | --------------------------- | --------------------- |
| 아이 상세 | "찾을 수 없는 프로필이에요" | 서버가 죽었을 뿐      |
| 10년 뒤   | "측정을 먼저 해 주세요"     | 이미 쟀는데도         |
| 가족      | "가족 더하기" 빈 화면       | 가족은 그대로 있는데  |
| 측정      | 뼈대인 채로 영영 멈춤       | 꺼진 쿼리의 대기 상태 |

**못 불러온 것을 없는 것으로 그리고 있었다.** 건강 정보를 다루는 앱이
"그런 아이는 없습니다" 라고 말하면 안 된다. 16개 화면을 고쳤다.

## 10. 기술 선택

| 무엇       | 무엇을 썼나                    | 왜                                         |
| ---------- | ------------------------------ | ------------------------------------------ |
| 프레임워크 | Next.js 16 (App Router)        | 라우팅·이미지 최적화·PWA 를 한 틀에서      |
| 언어       | TypeScript                     | `any` 금지. 백엔드 응답 타입은 한 곳에서만 |
| 서버 상태  | TanStack Query                 | 서버 데이터를 화면에 복사해 두지 않는다    |
| 전역 상태  | Zustand                        | 서버가 모르는 것만 (역할, 타이머)          |
| 스타일     | Tailwind v4                    | 색은 토큰으로만. 임의값 금지               |
| 가짜 서버  | MSW                            | 백엔드 없이 도메인 규칙까지 구현해 개발    |
| 연출       | three.js · CSS View Transition | 조각 수백 개가 동시에 움직일 때만 WebGL    |

**백엔드 타입은 손으로 쓰지 않는다.** 실제 API의 OpenAPI 문서에서 자동 생성한다.

```bash
npx openapi-typescript http://localhost:8080/v3/api-docs -o src/lib/api/schema.ts
```

| 무엇                                      | 왜 필요한가                                      |

| 기획서 확장 (7) **AI 체력 나이**          | 지금은 백분위를 점수로 쓰고 있다                 |
