# 우리가족 체력키움 — 프론트엔드 중간보고

국민체력100 공개데이터 기반 가족 체력 서비스 · 담당: 프론트엔드

## 무엇을 만들었나

국민체력100 측정 기록을 가족 단위로 읽는 웹앱(PWA)이다. 앱스토어에 올리지 않고
링크로 들어오며, 홈 화면에 설치하면 앱처럼 열린다.

한 계정으로 부모와 아이가 같이 쓴다. 하단 탭바를 두지 않았다. 부모와 아이가 같은 바를
쓸 수 없고, 다섯 칸 탭바는 어느 앱에나 있는 모양이라 이 서비스가 무엇인지 말해 주지
않는다. 대신 **역할 자체를 내비게이션으로** 삼아 로그인 직후 부모인지 아이인지 고르고,
그 뒤로는 각자의 홈 하나가 중심이 되게 했다. 총 32개 화면이다.

## 핵심 주장 — 코치 제안은 미션이 아니다

이 서비스가 다른 운동 앱과 갈리는 지점이다. 주간 코치가 만든 것은 **제안**이고,
**보호자가 승인해야** 비로소 **미션**이 된다. AI가 짜 준 계획이 보호자 확인 없이
아이에게 내려가지 않는다. 아동 대상 서비스에서 이 경계가 없으면 안 된다고 보고
화면 문구까지 여기에 맞췄다. 승인 전에는 "미션"이라는 단어를 쓰지 않고, 승인 버튼은
보호자 프로필에만 렌더링된다.

브라우저에서 확인한 결과는 제안 만들기 전 0건 → 제안을 만든 직후에도 **0건** →
보호자 승인 후 1건이다.

## 아이를 평가하지 않는다

기획서 페르소나(초4 서준 · 워킹맘 은영)에서 규칙을 뽑아 화면에 옮겼다.
아이에게는 신체 점수 하나와 이번 주에 움직인 날, 오늘 할 운동만 보여준다. 등급,
형제 비교, 약한 항목은 보여주지 않는다. **연속 기록(streak)을 쓰지 않는다** —
하루 빠지면 0으로 돌아가고 그건 벌이 되기 때문이다. 아무 일도 없었던 주에
"0분 · 미션 0／0" 같은 0의 나열도 띄우지 않는다.

## 가족을 잇는 순환

아이가 운동을 마치면 "엄마·아빠한테 알리기"를 누르고, 부모 홈에 "서준이 기다리고
있어요"가 뜬다. 부모는 **정해진 문구를 고르기만 해도** 칭찬을 보낼 수 있다. 퇴근하고
지친 부모에게 글쓰기를 시키면 그날로 안 보내기 때문이다. 칭찬은 부모만 보낼 수 있고,
받은 말을 개수 목표로 만들지 않는다.

## 모르는 것을 아는 척하지 않는다

서버가 진짜로 아는 건 유튜브 재생 진행률과 앱 내 타이머 둘뿐이라, 자기 신고 기록에
"자동 인증"을 붙이지 않는다. 10년 뒤 화면은 "당신은 이렇게 됩니다"가 아니라 "지금과
같은 조건의 10년 위 연령대는 여기 있습니다"로 쓰고 신뢰구간을 같이 그린다. 규준이
비어 있는 항목은 0%가 아니라 비어 있게 그린다.

## 검증

손으로 눌러 보던 것을 검사 스크립트로 옮겼다. 30개 화면의 콘솔 오류·빈 화면·제목
개수·누름 자리 크기와 아이 모드에서 부모용 표현이 새는지를 자동으로 본다. 특히
**백엔드를 500으로 막고 여는 검사**에서 가장 많이 잡혔다 — 서버가 죽었을 뿐인데
"찾을 수 없는 프로필이에요", "측정을 먼저 해 주세요"라고 말하는 화면이 여럿이었고,
16개 화면을 고쳤다.

## 남은 일

실제 백엔드 연동 후 목 서버 제거, 측정 이력 조회 API 요청, AI 체력 나이 반영.
